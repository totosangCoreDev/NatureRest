# NatureRest - Landing Page หมอนยางพาราแท้ 100%

โปรเจกต์ Landing Page สำหรับขายหมอนยางพาราธรรมชาติ ออกแบบด้วยสไตล์ **Premium & Minimal** (Quiet Luxury) เน้นความสะอาดตา การใช้งานที่ง่าย และการแสดงผลที่รวดเร็ว

## ✨ คุณสมบัติ (Features)
- **Modern Design**: ใช้ Typography สมัยใหม่ (Outfit & Noto Sans Thai) พร้อมโทนสีธรรมชาติ
- **Responsive Design**: รองรับการใช้งานได้สมบูรณ์บนทุกหน้าจอ (Desktop, Tablet, Mobile)
- **Scroll Animations**: มีระบบตรวจจับการเลื่อนหน้าจอเพื่อแสดงผลอนิเมชั่น (Reveal on Scroll)
- **SEO Optimized**: ใช้ Semantic HTML และใส่ Meta Tags ครบถ้วนตามมาตรฐาน
- **Fast Performance**: ใช้ Vanilla JavaScript และ CSS ทำให้โหลดหน้าเว็บได้รวดเร็ว

## 🛠️ เทคโนโลยีที่ใช้ (Technologies)
- **HTML5**: สำหรับโครงสร้างหน้าเว็บ
- **CSS3 (Vanilla)**: สำหรับการจัดเลย์เอาต์ (Flexbox & Grid) และการปรับแต่งสไตล์
- **JavaScript (ES6)**: สำหรับระบบ Scroll Interaction และการตอบสนองของผู้ใช้
- **Google Fonts**: Outfit และ Noto Sans Thai

## 📂 โครงสร้างไฟล์ (Project Structure)
```text
/
├── index.html          # ไฟล์หน้าหลักของเว็บไซต์
├── style.css           # ไฟล์รวบรวมสไตล์และการออกแบบทั้งหมด
├── script.js           # ไฟล์ควบคุมการทำงานและอนิเมชั่น
├── hero.png            # รูปภาพหลักส่วนหัว (Hero Image)
├── pillow-contour.png   # รูปภาพสินค้า รุ่น Contour
└── pillow-standard.png  # รูปภาพสินค้า รุ่น Standard
```

## 🚀 วิธีการใช้งาน (Getting Started)
1. ดาวน์โหลดหรือ Clone โปรเจกต์นี้ไปยังเครื่องคอมพิวเตอร์ของคุณ
2. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ (Chrome, Firefox, Safari) เพื่อดูผลลัพธ์
3. หากต้องการแก้ไขข้อมูล ให้เปิดไฟล์ `index.html` และแก้ไขเนื้อหาในส่วนที่ต้องการได้ทันที
